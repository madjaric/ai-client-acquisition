01Introduction

LeadFlow AI is a full-stack lead generation and outreach automation tool built for digital agencies. It combines Google Maps data sourcing, Gemini AI scoring, personalized email generation, and Gmail SMTP sending into a single dashboard.

The tech stack is Node.js + Express + SQLite on the backend, with plain HTML/CSS/JS on the frontend. All data is stored locally in a SQLite database — no external database required.

02Quick start

The app is live at leadflowai-2nl0.onrender.com. No local setup needed for users. For self-hosting:

git clone https://github.com/your-repo/leadflow-ai
cd leadflow-ai
npm install
cp .env.example .env   # fill in your API keys
node server/index.js

The dashboard will be available at http://localhost:3000/dashboard.html.

03Environment setup

Copy .env.example to .env and fill in your values:

# Required for AI scoring + email generation
GEMINI_API_KEY=your_gemini_key_here

# Required for Lead Discovery (Google Maps)
SERPAPI_KEY=your_serpapi_key_here

# Required for SMTP email sending
GMAIL_USER=your@gmail.com
GMAIL_APP_PASSWORD=your_16char_app_password

# Optional
PORT=3000
NODE_ENV=production
DB_PATH=./data/database.sqlite
Security: Never commit your .env file to version control. The app reads keys server-side only — they are never exposed to the frontend.

04Lead Discovery

The Discovery page searches Google Maps via SerpAPI. Enter a business type and city, and LeadFlow returns businesses with name, address, rating, review count, website, and phone.

If SERPAPI_KEY is not set, the app automatically falls back to realistic mock data so you can still test the full flow.

Tip: Use the "Export without website" button to download a CSV of leads with no website — these are your best cold outreach targets.

05AI Lead Scoring

Scoring uses Gemini 2.5 Flash Lite and evaluates each lead on: web presence, review quality, ad spend signals, business maturity, and fit score. Returns a 1–10 score with:

  • Tier — A (highest value), B, C, D
  • Estimated monthly value — projected client revenue
  • Confidence — high / medium / low
  • Red flags — list of risk factors
  • Recommended action — what to do next

06Outreach Generator

Generates three formats simultaneously using Gemini 2.5 Flash:

  • Subject line — under 8 words, specific and curiosity-driven
  • Email body — 100–150 words, industry hook, one CTA
  • LinkedIn/Twitter DM — 40–60 words, conversational tone

Tone can be overridden: professional, casual, direct, friendly. All generated messages are saved and linked to the originating lead.

07SMTP Email Sending

LeadFlow sends emails via Gmail SMTP (port 465 SSL). Requires a Gmail App Password — not your regular Gmail login. Create one at myaccount.google.com/apppasswords.

All sends are logged to the email_logs table with status, timestamp, and error details.

08Campaigns

Campaigns let you group leads for organized outreach. Each campaign tracks which leads have been contacted, email status, and send timestamps. Leads can be added to multiple campaigns.

APILeads

GET/api/leads

Returns all leads. Supports ?status=, ?industry=, ?search=, ?limit=, ?offset=.

POST/api/leads

Create a lead. Body: { business_name, industry, location, website?, notes? }.

PATCH/api/leads/:id

Update any lead field. Body: any subset of business_name, industry, location, website, notes, status.

APIScoring

POST/api/score-lead

Score a lead. Body: { lead_id }. Returns { score: { lead_score, tier, estimated_value_range, confidence, reasoning, red_flags, recommended_action } }.

GET/api/score-lead/ranked

Returns leads ordered by score. Supports ?tier=A, ?min_score=7.

APIDiscovery

POST/api/discovery/search

Search businesses. Body: { keyword, limit? }. Returns { success, data: [...], source, keyword }.

POST/api/discovery/import

Bulk import. Body: { businesses: [...] }. Returns { summary: { imported, skipped, failed } }.

POST/api/discovery/import-one

Import single business. Body: { business_name, location, industry, website?, notes? }.

GET/api/discovery/source

Returns { source: "serpapi" | "mock" }.

APIHealth

GET/api/health

Returns system health including DB status, uptime, memory, and environment. Used by the Status page and dashboard connection indicator.
