01Credential Storage

API keys (Gemini, SerpAPI), SMTP passwords, and other credentials are stored exclusively as environment variables on the server. They are never:

  • Committed to version control
  • Returned in any API response
  • Stored in the SQLite database
  • Exposed to the frontend JavaScript
Important: If you share your credentials in a chat, email, or public place, rotate them immediately. We cannot un-expose a leaked key.

02API Security

All /api/* routes are protected by:

  • Helmet.js — sets security headers including CSP, HSTS, and X-Frame-Options
  • express-rate-limit — default 100 requests per 15 minutes per IP, configurable via RATE_LIMIT_MAX_REQUESTS
  • Input validation — all request bodies are validated before processing
  • CORS — configurable origin restrictions via CORS_ORIGIN env variable

03Database Security

Data is stored in a SQLite file at the path specified by DB_PATH. The file is never served as a static asset. All queries use parameterized statements — no string concatenation — making SQL injection impossible.

04Email Security

SMTP credentials are validated server-side before the first send. Passwords are never logged or cached in memory beyond the active transporter lifetime. We use Gmail App Passwords rather than your main account password, limiting blast radius if credentials are compromised.

05Responsible Disclosure

If you discover a security vulnerability, please report it to security@leadflowai.com. We aim to respond within 48 hours and resolve critical vulnerabilities within 7 days. We do not pursue legal action against good-faith security researchers.

06Infrastructure

LeadFlow AI is hosted on Render.com with automatic HTTPS, DDoS protection, and daily backups. All traffic is served over HTTPS with TLS 1.2 minimum.
