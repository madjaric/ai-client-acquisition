🏗Infrastructure

LeadFlow AI is hosted on Render, running on isolated containerized services. Our infrastructure uses:

  • Isolated containers per service with no shared runtime environments
  • Automated dependency vulnerability scanning on every deployment
  • Environment variables and secrets management via encrypted vaults
  • Read-only production file systems where possible
  • Automatic TLS certificate provisioning and renewal

Database Security

All databases use private networking and are not publicly accessible. Connection strings are rotated quarterly. Database access is audited and requires IP allowlisting for team members.

🔑Authentication & Account Security

We protect your account with several layers of security:

  • Password hashing: Passwords are stored using bcrypt with a high work factor — we never store plaintext passwords
  • Session management: Sessions are invalidated on logout and expire automatically after inactivity
  • Rate limiting: Login endpoints are rate-limited to prevent brute-force attacks
  • CSRF protection: All state-changing requests require valid CSRF tokens
  • Secure headers: All responses include security headers (HSTS, CSP, X-Frame-Options)

We recommend using a unique, strong password for your LeadFlow AI account and enabling MFA when available.

📧Email & SMTP Security

When you use LeadFlow AI's email sending features:

  • SMTP credentials are stored encrypted and never logged in plaintext
  • We do not retain the body of emails you send beyond what's shown in your own audit log
  • All outgoing emails include proper authentication headers (SPF, DKIM guidance is provided)
  • Our sending infrastructure uses TLS for all connections to recipient mail servers

🤖AI & Third-Party APIs

When generating emails or scoring leads, we send contextual prompts to OpenAI and Anthropic APIs. We do not include:

  • Your account credentials or payment information in prompts
  • Personally identifiable information beyond what you explicitly include in lead notes
  • Cross-user data — each prompt is isolated to your session

Our agreements with OpenAI and Anthropic include data processing terms that prohibit use of API submissions for model training without consent.

🐛Vulnerability Disclosure

Responsible Disclosure Program

If you discover a security vulnerability in LeadFlow AI, we ask you to report it responsibly. Please email security@leadflowai.com with details including:

  • A description of the vulnerability and its potential impact
  • Steps to reproduce
  • Any proof-of-concept code (if applicable)

We will acknowledge your report within 48 hours, provide status updates, and work to resolve confirmed issues promptly. We do not take legal action against good-faith security researchers.
